# Positioning

## Core Positioning Statement
Appsmith is the open-source low-code platform that lets engineering teams build custom internal tools 10x faster, with full code control and self-hosting options that commercial alternatives can't match.

## For Appsmith Agents
Appsmith Agents is the enterprise AI platform that gives your sales, support, and CS teams context-aware AI assistants that work inside the tools they already use, not in a separate tab.

## Before / After

### Before Appsmith
- Engineers waste weeks building admin panels and dashboards from scratch
- Internal tools are fragmented, insecure, and impossible to maintain
- Business teams wait in ticket queues for simple data interfaces
- Every internal tool is a custom React app that nobody wants to maintain

### After Appsmith
- Drag-and-drop UI + JavaScript = custom tools in hours, not weeks
- Centralized platform with Git integration, RBAC, and audit logs
- Business teams get self-serve tools built on their actual data
- One platform for all internal tooling with consistent security and UX

## Key Differentiators
1. **Open source**: Full code transparency, community-driven, no vendor lock-in
2. **Self-hosting**: Deploy on your infrastructure, your data never leaves
3. **Developer-first**: Full JavaScript control, Git integration, CI/CD support
4. **Cost efficiency**: Free tier with unlimited apps, predictable pricing at scale

## Against Retool
- Retool is closed-source, $50/builder/month for Business plan
- No self-hosting flexibility (VPC only on Enterprise)
- Appsmith: open-source, $15/user/month, self-host anywhere

## Against Building In-House
- 10x faster than coding from scratch
- Pre-built widgets, connectors, auth, and RBAC out of the box
- Engineers can focus on core product instead of internal tools
