# Competitors

## Direct Competitors

### Retool
- **Positioning**: Enterprise low-code for internal tools
- **Strengths**: 100+ components, native mobile, strong enterprise features, large customer base
- **Weaknesses**: Expensive at scale ($50/builder Business plan), closed-source, vendor lock-in
- **Win pattern**: Cost-conscious teams, open-source requirement, self-hosting needs
- **Loss pattern**: Teams wanting turnkey enterprise support, native mobile apps

### ToolJet
- **Positioning**: Open-source internal tool builder with AI-native features
- **Strengths**: Free open-source, Python support, built-in database, AI app generation
- **Weaknesses**: Quality/stability issues reported, smaller community
- **Win pattern**: JavaScript preference, larger community, more mature platform
- **Loss pattern**: Teams wanting Python support or AI-native building

### Budibase
- **Positioning**: Open-source low-code for quick internal CRUD apps
- **Strengths**: Built-in CouchDB, good for simple apps, self-hosted free tier
- **Weaknesses**: Limited customization, fewer components, less mature
- **Win pattern**: Complex app requirements, JavaScript/API heavy workflows
- **Loss pattern**: Simple CRUD apps where Budibase is faster to set up

## Indirect Alternatives

### DIY / Custom React/Vue apps
- Most common "competitor" — engineers just building from scratch
- Win by showing 10x speed advantage while keeping code control

### Superblocks
- Developer-focused, strong API orchestration
- More expensive, less community

### Microsoft Power Apps
- Enterprise Microsoft shops
- Limited outside Microsoft ecosystem

### Status Quo / Spreadsheets
- Business teams using Google Sheets and manual processes
- Win by showing operational risk and data integrity improvements

## Competitive Landmines
- "Appsmith is just for simple CRUD apps" — Counter with complex workflow examples
- "Open source means less support" — Counter with Enterprise tier SLAs
- "No native mobile" — Acknowledge, position as web-first for internal tools
