# Segment: Open Source First

## Segment Definition
Engineering teams and organizations that prioritize open-source software, want to self-host, audit source code, and avoid vendor lock-in. Often active in OSS communities and GitHub.

## Qualifying Criteria
- **Values**: Strong open-source culture (OSS contributions, open-source stack)
- **Signals**: GitHub stars on Appsmith, OSS contributions to related projects, self-hosting mentions in job posts
- **Behavioral**: Visiting GitHub repo, self-hosting documentation, community Discord/forum
- **Tech stack**: Predominantly open-source stack (Linux, PostgreSQL, Docker, Kubernetes)

## Estimated Volume + Sources
- ~25,000 accounts globally
- Source: Appsmith GitHub stargazers (35k+), community members, self-hosting documentation visitors
- Validation: GitHub API analysis, community forum membership, self-host deployment tracking

## Evidence
- Appsmith has 35,000+ GitHub stars indicating strong OSS interest
- Self-hosting documentation is among the most visited pages
- Community Discord has active self-hosting discussion channels
- Many enterprise teams start with self-hosted free tier before upgrading

## Primary Pain Points
1. **Vendor lock-in fear**: Don't want to depend on a SaaS that can change pricing or features
2. **Data sovereignty**: Need data to stay on their infrastructure for compliance or policy
3. **Code auditability**: Security team requires ability to audit source code
4. **Customization**: Need to extend or modify the platform for their specific needs
5. **Cost predictability**: Want infrastructure cost only, not per-seat SaaS pricing

## Messaging Hooks
- "Self-host, audit the code, contribute back. No vendor lock-in."
- "Your internal tools platform should be as open as the rest of your stack"
- "Free forever for self-hosted. Upgrade only when you need enterprise features."

## Recommended Angles
- Primary: **"Own your stack, own your data"** (messaging/angles.md #3)
- Secondary: **"Stop paying Retool tax"** (messaging/angles.md #1)

## Campaign Assignment
- Active: `community-to-business` campaign
- Channel mix: GitHub (primary), community Discord, developer conferences, technical blog posts
